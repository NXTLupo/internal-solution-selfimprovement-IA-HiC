# About email images best practices

Source: [Klaviyo documentation](https://klaviyo.zendesk.com/hc/en-us/articles/115005253688-About-email-images-best-practices)

Learn about best practices when using images in Klaviyo emails, including size recommendations and how to add images.
Consider the following when creating images for use in emails:
To add an image into a template:
If you are uploading an image, the maximum image size you can upload is 10 MB.
Klaviyo includes an automatic image compression tool as part of the image upload process to help you balance image clarity with fast load times. Note that this feature isn't supported for GIFs.
With Compare selected in Upload settings, uploading an image opens Select upload version, where you can compare your original file with a compressed version. Each preview shows the file size, along with the percentage difference between them. Select Original or Compressed above each preview to choose which version to upload. Klaviyo adds a Recommended badge on its suggested choice. However, you can override this if you notice a loss of clarity in the compressed version, which can happen with smaller original files.
The first image comparison panel is open by default. For additional images, the panel is closed by default when the original is recommended. If you uploaded multiple images at once, review and choose your preferred option for each image individually.
Click Upload for 1 image or Upload all for multiple images to finish uploading your selections.
If you want to skip the review step when uploading images, adjust your Upload settings. When you upload an image, you'll see an Upload settings button.
Your choice here saves for future uploads. You can select:
Select your preference, then click Back to return to the upload window.
Images in image blocks, split blocks, and table blocks can easily be cropped. Dynamic images cannot be cropped in the editor.
To resize an image, use the resize sliders in the canvas. 
For HTML templates that reference local image files, upload a ZIP file containing those images during the import process. Match the filenames and folder paths in the ZIP to the references in your HTML. Images referenced by a public URL don't need to be included in the ZIP.
For imported Mailchimp templates, Klaviyo automatically copies images hosted at gallery.mailchimp.com. Images hosted at other URLs remain linked to their original location, so keep those images publicly available or upload them to Klaviyo and update the URLs in your template.
In the HTML editor, place your cursor where the image URL belongs in an <img> tag (inside the src quotes), then click Insert image to upload or choose an image. Selecting an image inserts its URL at the cursor; it does not insert a complete image tag.
If you are concerned that your images are not rendering as cleanly or crisply in your templates as you'd like, you can take steps to improve image quality.

Klaviyo supports the following image types: JPEG, PNG, and GIF.
You can upload WebP files, and use Klaviyo's built-in converter to convert them to PNG files. However, conversion is not supported for animated WebP files.
If you have other file formats like PSD or SVG, you will need to convert them to a supported image type before uploading.
Learn more about which image types are the best for your email.
Images you upload to Klaviyo are stored under Content > Media & brand > Images. Deleting an image from your image library will not remove the image from any templates where it is currently used.
