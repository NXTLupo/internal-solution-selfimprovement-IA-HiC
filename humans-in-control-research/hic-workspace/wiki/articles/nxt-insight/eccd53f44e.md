Figma-to-clean-HTML tools break on pixel-positioning and gibberish class names

A r/webdev practitioner tested four Figma-to-HTML tools for a static marketing site and found Locofy produced brittle, heavy pixel-based positioning that breaks when a font size changes or a line is added, with automated gibberish class names, while Anima produced semantic tags and readable class names in a stylesheet [articles/reddit-deep-r-webdev/d80f2940c2.md#c0]. This is a direct warning for the Deciem pipeline: naive Figma export is not maintainable, sendable email HTML, which is why a component-mapping and MJML abstraction step is required rather than raw export.
