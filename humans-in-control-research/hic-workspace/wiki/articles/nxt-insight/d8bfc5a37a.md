Code Connect stops agents from fabricating components, cutting rework and token spend

Figma's engineering team ran the same design, prompt, and model with and without Code Connect and found that without it the agent fabricated its own versions of components, such as building a stepper out of progress bars. With Code Connect, the MCP server substitutes generated React with production-accurate snippets pointing at the correct design-system component and property values. For an email blueprint this is the concrete mechanism that binds generated markup to a reusable component library instead of drifting.

Without Code Connect, the agent would sometimes fabricate its own version of components: say, build a stepper out of progress bars. [articles/figma-blog/40aa3ff795.md#c2]
