A named human must stay accountable as agents gain autonomous control over workflows

Charlie Sutton warns that agents are soon getting increasingly autonomous control over workflows, so a person must remain accountable for what those agents do. VentureBeat's governance analysis sharpens the mechanism: enterprises deploy fleets where any agent might call any other, complexity compounds with the number of paths between agents, and the org chart stops at 'deploy the agent' without naming the human who answers for it. Every agent needs its own identity, scoped authority, and a named human sponsor — the accountability substrate any approvals or notification design must respect.

Fairly soon, we’re going to be giving agents increasingly autonomous control over workflows. We need to make sure a person remains accountable for what those agents do.
