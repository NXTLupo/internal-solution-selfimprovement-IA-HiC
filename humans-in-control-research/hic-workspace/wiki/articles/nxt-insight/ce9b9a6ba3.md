Specialized agents export a spec to Notion and open a token PR for human review

One team runs specialized agents that guide the designer toward consensus, then export a templated specification document to Notion and connect to a design-system MCP server to create or update design tokens. Both the design-token PR and the spec document are submitted for review before the designer works the advanced design in Figma and the dev builds from spec plus mockups. This is a working reference architecture for the approvals-and-harnessed-execution axis: agents propose, humans approve via PR, execution stays deterministic through the token PR.

It also connects to our DS MCP server to create/update design tokens. Both the design token PR and the specification document are submitted for review.
