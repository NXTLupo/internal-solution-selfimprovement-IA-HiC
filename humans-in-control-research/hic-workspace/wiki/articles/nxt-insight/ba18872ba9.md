The code-to-Figma reverse direction stays unsolved because agents redraw instead of instancing components

The forward direction (Figma to code) is roughly solved at ~80% correctness, but the reverse breaks the source of truth [articles/reddit-deep-r-figmadesign/0546ec2185.md#c0]. Figma's AI 'builds from links or screenshots but just redraws what it sees; it won't replace elements with real component instances' [articles/reddit-deep-r-figmadesign/0546ec2185.md#c0]. Cloning a site from HTML yields 'a button drawn, not the button component,' so the rebuilt file looks right but is detached from the system [articles/reddit-deep-r-figmadesign/0546ec2185.md#c0]. This directional asymmetry is a hard capability limit for any round-trip harnessed-execution use case.
