Design.md and Tokens.md markdown files are the emergent standard for feeding agents design context

A repeatable practitioner pattern: a standardized markdown file (design.md, Tokens.md) that lists tokens, target framework, layout information, and component code examples in a format agents read effectively. Files are 100% tokenized with a plugin checking design docs for best practices; every color, spacing, and text value a token or variable. Skills are generated from source and updated when source changes, so a second brand reuses the same components with different token values. This markdown-context convention is the interoperability glue between the design system and Figma's agents.

Design.md file is your answer. It’s a standardized markdown file format that solves exactly what you’re saying.
