Skills are markdown instruction files that teach agents team intent, not code plugins

Figma's skills are markdown files that define which steps an agent takes, what sequencing to follow, and which conventions to abide by, bridging the knowledge gap so agents produce durable, brand-aligned designs. Authoring one requires no plugin or code. A foundational /figma-use skill underpins all others, giving agents a shared model of how Figma works; teams customize from there. This is the primary extensibility point for the white paper's skills section.

Anyone can author a skill and writing one doesn't require building a plugin or writing code. At the core is a foundational Figma skill; /figma-use; which all other skills build on.
