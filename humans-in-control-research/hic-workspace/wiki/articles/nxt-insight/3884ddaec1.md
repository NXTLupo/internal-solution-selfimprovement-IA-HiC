Figma charges for agent MCP usage, which practitioners say undercuts adoption

Reddit commenters on Figma's canvas-to-agents announcement object that Figma charges for MCP usage, arguing nothing should prevent the MCP from running locally and that paying to use third-party tools to overcome Figma's own bottlenecks doesn't wash. One warns no one will pay when they already pay for Claude Code or GitHub Copilot. This pricing friction is a commercial limitation on Figma's agentic extensibility.

Figma are shooting themselves in the foot by charging for this... they expect people to pay to use 3rd party tools to overcome Figma's bottlenecks? [articles/reddit-deep-r-figmadesign/444da33eda.md#c0]
