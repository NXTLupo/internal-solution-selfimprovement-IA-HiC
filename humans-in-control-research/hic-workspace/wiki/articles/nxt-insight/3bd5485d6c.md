AI agents ignore the existing UI kit and redraw one-off components instead of extending it

The dominant practitioner grievance: agents draw a new button slightly different from the Button component already in the codebase, adding inconsistency. One designer found Claude Design duplicated components and icons, drawing the same icon differently by the third screen, and Figma Make accepted a UI kit but never treated it as the source of truth, building around components rather than from them. The critical failure is extension; when a prop or component is missing, the system leaves the capability missing or creates a one-off rather than extending the kit.

If a prop or component was missing, the system didn't extend the kit. It either left the capability missing or created a one-off implementation, putting me back where I started.
