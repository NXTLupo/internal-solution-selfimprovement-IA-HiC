Custom tools and generative plugins let the agent extend the canvas itself

Figma's agent update adds custom tools, real context, and skills so designers can 'shape your tools just as you shape your designs.' Designers can prompt the agent to build reusable generative plugins built on PropsKit so they look native, and author shader effects and fills. Product designer Edward Chechique describes going 'from zero possibilities to great possibilities' by asking for tools directly instead of waiting on a developer. This is the extensibility surface the white paper's design and AI-extension use cases depend on.

Now you can prompt the design agent to build reusable plugins. Because they use PropsKit, these generative plugins look and feel native to Figma. [articles/figma-blog/e372681f45.md#c1]
