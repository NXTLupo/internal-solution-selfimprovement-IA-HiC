A layered tool architecture with typed composable actions beats hundreds of standalone tools

Webflow found task-oriented design created a large overlapping tool surface agents could not navigate efficiently, so it grouped related capabilities into broader domain-level tools with typed composable actions, giving agents a structured, navigable map while keeping the top-level tool space manageable. It also introduced filesystem abstractions with code representations of projects so agents operate with familiar shell-style workflows. This tool-surface design is a direct requirement for the white paper's harnessed-execution section.

Instead of exposing hundreds of standalone tools, we grouped related capabilities into broader domain-level tools with typed composable actions inside them.
