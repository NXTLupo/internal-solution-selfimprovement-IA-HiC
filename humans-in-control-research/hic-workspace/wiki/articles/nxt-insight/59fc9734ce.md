Code Connect cuts token use 29.5% and lifts code quality a full point when agents build from real components

Figma's eval harness ran 27 design-to-code test cases with and without Code Connect across two React design systems [articles/figma-blog/40aa3ff795.md#c3]. With Code Connect, median task duration fell 19.6%, token usage fell 29.5%, and code quality rose a full point on a 1-4 Likert scale [articles/figma-blog/40aa3ff795.md#c1]. The single biggest driver was Code Connect coverage - the share of handoff designs made of Code-Connected components [articles/figma-blog/40aa3ff795.md#c4]. Without it agents hand-built non-functional tabs and churned on custom CSS. For Deciem this argues that connecting Figma email components to a real MJML component library is the highest-leverage investment.
