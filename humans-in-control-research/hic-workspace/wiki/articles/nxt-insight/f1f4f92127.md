Deterministic validation sits between an agent's decision and execution, never letting the LLM be sole authority

AWS's retail guidance is explicit: never let an LLM be the sole authority on a revenue-impacting action, using hard-coded business logic and API calls to a rules engine that return yes or no without involving the LLM. For an email pipeline this is the pattern that qualifies output as sendable: brand-compliance and HTML-validity checks run as deterministic gates, not model judgment. The principle 'the model proposes; deterministic rules and human oversight are executed' is the core QA design for automated email output.
