Agents draw one-off components instead of using the design-system kit already present

Practitioners repeatedly report that when asked to add an element to a screen, agents ignore the existing Button component and design tokens, drawing a new, slightly different one instead. A r/designsystems thread describes Claude Design duplicating components and icons across screens, and Figma Make building screens around a UI kit rather than treating it as source of truth. This is the central limitation blocking Figma agents from producing spec-consistent output.

I ask the agent to add a button to a screen, and instead of using the Button component sitting right there in the codebase, it draws a new one [articles/reddit-deep-r-designsystems/... ]
