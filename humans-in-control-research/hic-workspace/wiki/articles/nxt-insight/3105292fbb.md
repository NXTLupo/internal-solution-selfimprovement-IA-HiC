Agentic Resource Discovery lets agents find skills and tools at runtime instead of pre-installing them

The Agentic Resource Discovery (ARD) draft spec — developed by contributors from Microsoft, Google, GoDaddy, and Hugging Face — moves capability selection outside the LLM. Instead of install-first, use-later where a developer hardcodes an MCP server URL, a registry indexes capabilities with richer signals (publisher identity, representative queries, compliance attestations, tags) and exposes a REST search endpoint. Hugging Face's Discover Tool serves thousands of Skills, ML apps, and MCP Servers as ARD catalog entries. This discovery layer is the forward-looking extensibility path for how Figma skills and MCP tools could be found dynamically.
