MCP plus a coding agent is the working bridge from Figma files to code

Multiple practitioners route work through Figma's MCP and an external coding agent rather than the in-canvas agent. One gives Codex the Figma file and tells it what to do, including making an icon a component in the library then having AI update all placeholder instances to the new component. Another combines MCP with Skills to critique. This exposes the real extensibility topology for harnessed execution: MCP is the read/write interface, the harness (Codex/Claude) is the executor, and the design system is the constraint.

I just use MCP and Codex. I give it my Figma file(s) and tell it what I need done. [social-intelligence/reddit-deep/uxdesign/1uke7pb.md#c5]
