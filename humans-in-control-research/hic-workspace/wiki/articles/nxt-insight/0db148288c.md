MCP connectors pull external tool context into the agent and post updates back

MCP connectors bring context from GitHub, Atlassian, Slack, and other tools directly into the agent and can post updates back. The agent can attach files like a UX copy doc, reference other Figma files to get full component, token, and style structure, and search the web for live data. Figma's own MCP use spans pulling context from Slack, Asana, Notion, and Hex to build boards. For Deciem this defines the concrete MCP configuration surface: Figma libraries plus brand-guideline docs plus the sending platform, all reachable by the agents.
