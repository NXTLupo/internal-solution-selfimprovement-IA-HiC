Design drift between Figma and code is detected and reconciled by the agent

Agents can audit token usage in code versus the selected design and vice versa, and flag how to improve layer names to align Figma components with code components [articles/figma-blog/1e5fd6afb8.md#c3]. In the Astra workflow the designer notices color values are slightly off and spacing is tighter, then uses the /sync-figma-token skill to reach token parity, after which a structural problem - shifted button hierarchy and a wrongly-added secondary button - comes into focus [articles/figma-blog/cb124012b5.md#c3]. Drift detection between design tokens and code is a named skill category [articles/figma-blog/213ea4dcb6.md#c3]. For Deciem this is a required QA check before an email renders as intended.
