An LLM-as-judge review pass evaluates a draft against explicit pass-fail criteria before delivery

AWS describes a second model that reviews an agent's proposed response before it reaches the customer, evaluating specific criteria as a lightweight call with a focused prompt: 'Evaluate this draft response against these criteria. Pass or fail each one.' Reddit marketing-ops practitioners frame the same pattern as treating agents as junior QA staff whose output requires review. This is the direct precedent for an email QA agent that scores rendered HTML against brand and deliverability criteria before marking it sendable.
