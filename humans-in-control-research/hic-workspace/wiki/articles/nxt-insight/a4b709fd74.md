Source-of-truth breaks down when work splits across Figma files and git branches

Their landing point, Figma is truth before the build and code is truth after merge, is one they doubt survives reality. An engineer opening a design branch cannot tell which parts are deliberate design decisions and which the agent generated to make it run.
