The design source of truth is migrating from Figma toward the tokenized codebase

Practitioners report the source of truth for designers is moving toward the codebase, with some work in Figma and some in code. One team keeps Figma and Storybook fully synced and ready for AI agents to consume, letting designers own the design in both Figma and code for pixel-perfect implementation and motion in code. Another 'designs live in code while pairing with an engineer,' relying on the design system so states and interactions are already covered. This shift reframes where Figma's agentic extensibility sits relative to code-first agent workflows.
