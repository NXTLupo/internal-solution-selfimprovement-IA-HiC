Agent context is set by attached files, referenced Figma links, and web search

Figma frames context as what shapes what the agent makes: attaching files like a user interview, UX copy doc, or data report so the agent uses it as reference throughout; referencing another Figma file link so the agent gets the full structure; components, tokens, layout, styles; and can reproduce patterns rather than approximate from a flat image. This context-injection layer is the practical extensibility point for grounding agentic design output in project reality.

When you paste a Figma file link, the agent gets the full structure; components, tokens, layout, and styles; and can understand and reproduce design patterns, not just approximate them from a flat image.
