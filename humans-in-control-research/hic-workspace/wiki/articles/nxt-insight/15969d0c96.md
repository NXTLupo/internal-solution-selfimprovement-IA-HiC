Design systems must be re-authored to be machine-legible before agents can consume them

A r/DesignSystems practitioner started manually auditing a design system 'to prepare it for agents' and found it too time-consuming, so built System Lens to audit naming consistency, component structure, variants, and documentation coverage. The stated goal is to 'evaluate how well the Design System communicates its intent through its source of truth, and therefore how understandable and consumable it is for machines.' This reframes design-system integration for the objective: the system itself is an input that must be groomed for agent consumption, not just a token store.
