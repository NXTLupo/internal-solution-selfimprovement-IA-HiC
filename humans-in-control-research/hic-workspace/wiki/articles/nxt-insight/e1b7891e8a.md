Practitioners want a cyclical workflow where any role edits any surface with no round-trip loss

A r/figmadesign practitioner describes wanting a cyclical, not one-way, workflow: any person should jump in at any surface (Claude in the product repo, Figma Make, V0, Claude Design, or the Figma canvas) and move in a circle with no loss in each transition, assuming a 1:1 design system in Figma and in code. The root problem is that when a PM, dev, or founder changes things, getting those changes 1:1 back into Figma is the priority. This defines the round-trip requirement for Figma's agent extensibility.

I want a cyclical workflow. Any person should be able to jump in at any surface... You should be able to start anywhere and move on a circle with no loss in each transition.
