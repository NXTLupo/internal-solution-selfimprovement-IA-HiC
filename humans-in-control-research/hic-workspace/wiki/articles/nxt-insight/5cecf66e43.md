Code Connect coverage cut token use 29.5% and lifted code quality a full point in Figma's 27-case eval

Figma's eval harness ran 27 design-to-code test cases with and without Code Connect across two React design systems. With Code Connect, median task duration fell 19.6%, token usage fell 29.5%, and code quality rose a full point on a 1-4 Likert scale, with the single biggest driver being Code Connect coverage. Without it agents hand-built non-functional tabs and churned on custom CSS. For Deciem this argues that connecting Figma email components to a real MJML component library is the highest-leverage investment.
