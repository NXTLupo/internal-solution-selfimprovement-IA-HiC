Deterministic token linting beats trusting the agent to respect design tokens

Practitioners report that agents inferring a hex from a screenshot can conflict with the actual token value pulled via MCP, risking hallucination. The deterministic answer is a hook-style rule in the skill; 'Always use tokens for colors and spacing; if the Figma value doesn't match, refer to this skill's Tokens.md'; plus code-side linting that returns the same result every time. This is the deterministic-hooks surface: fully tokenized files and lint-for-token-use enforcement rather than probabilistic agent judgment.

On the code side. Lint for token use, don’t rely on an AI agent. Code tools have the same result every time and are designed to check stuff like hard coded colors.
