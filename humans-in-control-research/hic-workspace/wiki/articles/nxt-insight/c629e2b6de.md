Model Context Protocol is emerging as the open standard connecting agents to external tools and data

Anthropic introduced the Model Context Protocol as an open standard for connecting AI applications with external data and tools, and Google added Agent2Agent so agents on different systems can discover and coordinate. Nielsen Norman describes making design and UX standards available to AI tools via MCP servers and agent skills.
