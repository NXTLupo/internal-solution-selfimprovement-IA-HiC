Machine-readable design specs like DESIGN.md carry exact tokens plus human intent

In April 2026 Google Labs open-sourced DESIGN.md, a file format describing a product's visual identity to AI coding tools, grown out of Stitch [articles/nielsen-norman/010ac25d6d.md#c2]. It holds two content types: machine-readable exact values - colors, type sizes, spacing, corner radii - written so tools read them precisely, plus a plain human-readable part [articles/nielsen-norman/010ac25d6d.md#c2]. Figma's MCP can auto-generate a structured rules file outlining token definitions, component libraries, and naming conventions [articles/figma-blog/1e5fd6afb8.md#c2]. This gives Deciem a concrete artifact to codify email brand rules for the agents.
