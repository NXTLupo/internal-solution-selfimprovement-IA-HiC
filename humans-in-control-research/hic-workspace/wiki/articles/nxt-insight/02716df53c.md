A confidence threshold gates auto-write while low-confidence output routes to human review

Practitioners require the agent to output a suggested value, its evidence or source, and a confidence score, then auto-write only above a threshold such as 0.85 while below that queues for review. Automation applies updates only if confidence meets the bar, and agents write to a short whitelist of fields rather than overwriting identifiers. For Deciem this defines the auto-send decision rule: high-confidence low-risk output ships automatically, everything else escalates.

Add a confidence gate: require the agent to output (a) suggested value, (b) evidence/source, (c) confidence score. Auto-write only above a threshold (e.g., 0.85) [social-intelligence/reddit-deep/marketingautomation/1rrthqm.md#c0]
