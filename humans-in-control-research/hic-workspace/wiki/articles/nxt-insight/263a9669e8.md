Figma's design agent runs natively on the canvas, not as a bolt-on prompt box

Figma shipped a design agent that works directly on the canvas and is 'built for Figma,' framed around context rather than raw prompting. The product distinguishes an agent that helps you work efficiently from one that understands how you work, with context as the differentiator. This positions the agent as a collaborator inside the design surface rather than an external code generator. It is the foundational capability every extension pattern in the objective builds on.
