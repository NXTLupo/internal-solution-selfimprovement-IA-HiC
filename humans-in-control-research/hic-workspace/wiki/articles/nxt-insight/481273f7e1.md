Model Context Protocol is the open standard that binds agents to Figma libraries and brand docs

Anthropic introduced the Model Context Protocol as an open standard for connecting AI applications with external data and tools, and Google added Agent2Agent so agents on different systems can discover and coordinate. Nielsen Norman describes making design and UX standards available to AI tools via MCP servers and agent skills. For Deciem's pipeline this is the connective layer that would bind Figma libraries, brand guidelines, and design patterns to the agents exactly as the objective specifies.
