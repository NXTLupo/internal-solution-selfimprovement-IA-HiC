Skills encode team conventions as markdown that agents load only when relevant

Skills are self-contained instruction sets written as markdown files that shape how agents build on the Figma canvas [articles/figma-blog/213ea4dcb6.md#c1]. A foundational /figma-use skill gives agents a shared understanding of Figma structure, and all other skills build on it [articles/figma-blog/213ea4dcb6.md#c2]. Because skills encode specific steps, guidelines, and code, they make non-deterministic model behavior more predictable [articles/figma-blog/213ea4dcb6.md#c3]. In LangChain terms a skill is loaded via a load_skill tool so the agent reads full detail only for the skill it needs, avoiding one giant system prompt [articles/analytics-vidhya/e9862a91b9.md#c1]. This is the mechanism for encoding Deciem's brand and email rules per agent role.
