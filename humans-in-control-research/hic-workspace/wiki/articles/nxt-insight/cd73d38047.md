Design-system teams pre-audit and tokenize systems to make them agent-readable

A grassroots movement treats AI agents as first-class consumers of the design system. Practitioners manually audit component-by-component then build tools (System Lens, Spec Layer, Airframe) to check naming consistency, variants, and documentation coverage before agents touch the system. One team put an AI-focused guide into dedicated reference markdown files for prototyping and built a separate eval skill. Airframe uses a structure-patterns-blocks-blueprints progression with a lightweight MCP so agents discover rather than invent. This is the design-system-integration prerequisite the objective's implementation path depends on.

Making AI readability an actual requirement rather than an afterthought is increasingly important as more of the UI is being generated by AI.
