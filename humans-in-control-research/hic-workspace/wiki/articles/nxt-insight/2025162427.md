MCP servers ate tokens until teams swapped source code for optimized interface markdown

A design-system team ran an MCP server that served examples, readmes, and component source code, and it ate tokens like nothing; they swapped it for optimized Interface Markdown files. Another team ditched MCP for markdown plus CSV with a root-level AGENTS.md acting as a directory. NVIDIA data frames why this matters: agentic workloads consume 15x more tokens than a chat request, so token economy is a first-order constraint on Figma agent design.

We initially had just an MCP server that provided Examples, Readmes and the source code (!) of components. That ate tokens like nothing. We exchanged that for optimized Interface Markdown files.
