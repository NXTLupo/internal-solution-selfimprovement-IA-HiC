A Capsule UI author runs Figma variables through Token Studio to DTCG JSON to Style Dictionary to CSS custom properties, so the agent never sees hex values in components, only CSS variables it can look up. For AI, resolution runs Component to Semantic to Primitive so the agent references the semantic collection but can override at the component collection.
