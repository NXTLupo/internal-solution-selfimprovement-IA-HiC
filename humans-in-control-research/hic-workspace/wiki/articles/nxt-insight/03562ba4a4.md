Annotations feed agents accessibility, interaction, and content context

The Figma MCP server surfaces annotations as additional agent context, so 'Teams who use annotations to add context about accessibility, interaction behavior, or even content will see that information be reflected in their design-informed codegen' [articles/figma-blog/1e5fd6afb8.md#c3]. The MCP server can also audit differences between designs and codebase and 'Flag how to improve layer names to better align Figma components with code components' [articles/figma-blog/1e5fd6afb8.md#c3]. This annotation-and-audit channel is the concrete mechanism for accessibility-aware and content-aware agentic design in the white paper.
