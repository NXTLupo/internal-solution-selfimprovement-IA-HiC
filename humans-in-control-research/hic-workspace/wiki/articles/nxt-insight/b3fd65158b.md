Figma's MCP server targets Plugin API parity but still lacks image and custom-font support

Figma states the skills capability is native to the Figma MCP server, benefiting from Figma's security and reliability while opening access to surfaces like Code Connect. The explicit limitation: they are 'working toward parity with the Plugin API, starting with image support and custom fonts'; meaning as of the announcement, image support and custom fonts were not yet available through the MCP surface. This is a concrete extensibility ceiling for anyone planning implementation against the server.
