Deterministic design-system enforcement belongs in scripts, not probabilistic agent prompts

Practitioners converge that applying a design system is deterministic work best handled by a script the agent runs, while the agent's job is to identify the correct existing components rather than fill in the blanks in code. A separate r/designsystems thread argues prompt-based rules like CLAUDE.md are constraints without an anchor, holding only until context shifts. This points directly at the deterministic-hook extension point: a critic or QA script that rejects rogue CSS and off-token output.

Applying design system is meant for a deterministic work, which the script is for [social-intelligence/reddit-deep/uxdesign/1s7e3d1.md#c6]
