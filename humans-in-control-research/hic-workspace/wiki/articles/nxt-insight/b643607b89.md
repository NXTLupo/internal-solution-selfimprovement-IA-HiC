Design systems get rewritten for retrieval so agents grep chunks instead of reading pages

Practitioners describe rewriting docs for retrieval, not reading: every component page leads with a plain-language block stating what the component is for, when to use it versus neighbors, and a working code example. One AI-first setup keeps all rules in a single .md with descriptive headings because agents use grep to navigate, and a solid IA cuts token use. This documentation-as-context pattern is the prerequisite for Figma skills and design-system integration to work.

The docs got rewritten for retrieval, not reading. Humans skim a components page top to bottom. Agents grab chunks.
