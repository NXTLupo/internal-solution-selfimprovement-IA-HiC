Figma skills are markdown instruction files, not code plugins

Figma's skills are markdown files that define which steps an agent takes, the sequencing, and the conventions to follow, with no plugin or code required to author one [articles/nxt-insight/d786c2b6fc.md#c0]. A foundational /figma-use skill underpins all others, giving agents a shared model of how Figma works before teams customize [articles/nxt-insight/d786c2b6fc.md#c0]. Practitioners corroborate this: one design-system maintainer solved AI-agent drift by 'creating a set of skills for the ui-kit' and enforcing internal elements through AGENTS.md [articles/reddit-deep-r-designsystems/8acc3a5632.md#c3]. This markdown-authored, no-code extensibility surface is the primary lever the white paper's skills section must document.

Anyone can author a skill and writing one doesn't require building a plugin or writing code. At the core is a foundational Figma skill; /figma-use; which all other skills build on. [articles/nxt-insight/d786c2b6fc.md#c0]
