MCP servers give each agent a standardized, bounded interface to its own data source

AWS documents a swarm of specialized agents where each child agent communicates with its data sources through MCP servers hosted on a gateway, providing a standardized interface to internal and external sources. A Restaurant Swarm Agent orchestrates specialized child agents (Demand, Menu, Weather, Competitor Pricing) each bound to a dedicated MCP server. This is a directly transferable pattern for connecting Figma libraries, brand guidelines, and personalization tokens as discrete MCP servers to specialized email-production agents.

Each child agent communicates with its data sources through MCP servers hosted on Amazon Bedrock AgentCore Gateway. MCP servers provide a standardized interface [articles/aws-retail-blog/d295147ddc.md#c2]
