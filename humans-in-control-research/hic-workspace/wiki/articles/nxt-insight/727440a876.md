Multi-agent failure attribution remains unsolved, raising the stakes for logging

The Who&When benchmark formalizes automated failure attribution as identifying the failure-responsible agent and the decisive error step across 127 LLM multi-agent systems [articles/synced-review/af55070f79.md#c2]. Current methods - all-at-once, step-by-step, binary search - each trade cost against precision, and the paper's finding is that there is a long way to go [articles/synced-review/af55070f79.md#c2]. This means Deciem's pipeline must instrument every agent handoff with decision logs, since when a bad email slips through, tracing which agent caused it is not yet reliable without explicit logging.
