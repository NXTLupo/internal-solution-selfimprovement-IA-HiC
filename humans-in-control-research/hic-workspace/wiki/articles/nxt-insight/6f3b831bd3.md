Agents skip the thinking step, prompting a design-agent that validates before it draws

A recurring complaint: AI design tools 'were incredibly fast at generating screens... But they all skipped the part that actually matters, the thinking' [articles/reddit-deep-r-productdesign/239d02f691.md#c0]. The unmet questions include 'Is this idea worth building before you spend weeks on it? Is this screen accessible? Does it pass WCAG 2.2 AA?' [articles/reddit-deep-r-productdesign/239d02f691.md#c0]. This drove a designer to build an agent doing idea validation with a scored 0-100 analysis before touching a canvas [articles/reddit-deep-r-productdesign/239d02f691.md#c0]. The pre-design validation and accessibility-check pattern is a candidate critic-skill for the white paper.
