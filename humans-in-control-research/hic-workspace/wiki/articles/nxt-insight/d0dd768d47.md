Agents run inside stateful harnesses like Claude Code, Codex, and OpenClaw, not as bare models

Microsoft Research's Orchard work establishes that today's most capable agents rarely run as a bare model; they operate through sophisticated harnesses (Claude Code, Codex, OpenClaw) that manage multi-turn reasoning, tool use, and connections to external systems. Open training tools usually cannot handle these stateful, multi-process harnesses. Figma's own 'Claude Code to Figma' framing and practitioner exports to Claude Code confirm the canvas is one node in a broader harness. This grounds the harnessed-execution axis the objective names explicitly.
