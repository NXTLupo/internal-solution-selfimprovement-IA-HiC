Skills must teach the agent to read variables or token application fails

The skill is the mandatory bridge for token application: 'Figma Agent should apply your variables once you create them but you must create a skill that teaches it to read your variables and how to use them. You will want one no matter what agent you use' [social-intelligence/reddit-deep/figmadesign/1vz7ao0.md#c2]. Even with the skill, accuracy is imperfect and requires ongoing training [social-intelligence/reddit-deep/figmadesign/1vz7ao0.md#c2]. Tokens Studio is offered as a friendlier alternative for building an entire token system that must translate to code [social-intelligence/reddit-deep/figmadesign/1vz7ao0.md#c2]. This dependency; no variable adherence without a teaching skill; is a core implementation constraint.
