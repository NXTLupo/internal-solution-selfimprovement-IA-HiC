Designers want AI edits to flow back into Figma as the source of truth, not just forward to code

Practitioners describe a bidirectional gap: prototypes vibe-coded by PMs or edge cases built by developers need to travel back into Figma, which teams still treat as the source of truth [social-intelligence/reddit-deep/figmadesign/1ufllfw.md#c3]. One designer wants approved code prototypes rebuilt in Figma with components linked, and developer-added variants to make it back and stay linked [social-intelligence/reddit-deep/figmadesign/1ufllfw.md#c3]. This round-trip requirement is a core use case for Figma agents, approvals, and notifications.

it would be nice to be able to have those code updates and variants be able to somehow make it back into Figma, and have them be linked [social-intelligence/reddit-deep/figmadesign/1ufllfw.md#c3]
