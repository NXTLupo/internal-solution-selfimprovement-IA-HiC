The Figma MCP server exposes the concrete tool surface agents call

Figma's MCP server is the connective extensibility layer, providing named tools such as get_variable and make_design_system_kit that agents invoke to obtain design context [articles/reddit-deep-r-figmadesign/1b849d0af7.md#c0]. Figma's own blog documents that the MCP server lets agents generate component code aligned to team standards, identify where to apply or introduce design tokens, and audit token usage in code versus the selected design [articles/figma-blog/1e5fd6afb8.md#c3]. A context file defining token definitions, component libraries, and naming conventions acts as a system-level guide, reducing ambiguity in codegen [articles/figma-blog/1e5fd6afb8.md#c3].
