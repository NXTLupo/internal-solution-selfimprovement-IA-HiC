Figma's MCP get_design_context returns full implementation context, not a flat image

The Figma MCP server responds to a node reference with an actual React implementation of the selected frame, a reference screenshot, and download URLs for every embedded asset [articles/webflow-blog/5048e4f0e8.md#c2]. This single response carries layout, spacing, colors, and real content, which is what lets a general model port a design into a target without a purpose-built importer [articles/webflow-blog/5048e4f0e8.md#c1]. When a frame is inspected, the server sends components, styles, and variables to the agent [articles/figma-blog/1e5fd6afb8.md#c2]. For an email pipeline, this is the extraction layer that feeds the design-to-HTML agent.
