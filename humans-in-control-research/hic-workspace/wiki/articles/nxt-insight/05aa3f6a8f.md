Live design-system status APIs keep component truth in sync across platforms

eBay's OneExperience team built an internal Component Status API tracking design-system components across Figma, native, and open-source web-component libraries, so developers can check whether a component exists and is up to date with the Figma version [articles/figma-blog/fa5dca9c3a.md#c2]. Each library registers component names and versions - in Figma via component descriptions - creating a complete implementation picture [articles/figma-blog/fa5dca9c3a.md#c2]. Updates go live on their Playbook in under two minutes via a custom export plugin [articles/figma-blog/fa5dca9c3a.md#c2]. This is the governance backbone for keeping Deciem's email component library authoritative.

We can make an update in Figma and have it live on our Playbook site in under two minutes [articles/figma-blog/fa5dca9c3a.md#c2]
