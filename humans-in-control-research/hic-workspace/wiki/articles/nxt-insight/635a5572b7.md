The agent stops at Figma's edge: outside APIs still require classic plugins

Figma draws an explicit boundary on the agent's reach. Generative plugins live on the canvas and use PropsKit, but 'for anything that reaches outside Figma Design, like AI services or third-party APIs,' the guidance is to still use classic plugins. This is a hard limitation for the objective's harnessed-execution and notification use cases, which by definition cross the canvas boundary. Any implementation plan must route external calls through the classic plugin runtime, not the agent.
