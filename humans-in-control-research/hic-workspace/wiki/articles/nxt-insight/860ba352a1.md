Agents stop at extending the design system when a screen needs a new prop or component

A r/designsystems practitioner found both Claude Design and Figma Make stop at the exact boundary of designing against the real system and then extending it: if a prop or component was missing, the system left the capability missing or created a one-off implementation rather than adding it to the kit under project rules. This extensibility gap is what pushed the author to build a separate tool (Varelyo) that reads local React source and adds missing props or tokens to the system.
