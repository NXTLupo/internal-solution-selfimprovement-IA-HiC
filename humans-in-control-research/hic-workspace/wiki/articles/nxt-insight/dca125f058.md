Persistent memory and a supervisor sustain long-running agent work past a single context

NVIDIA's AVO architecture preserves progress beyond a single model context through persistent memory that carries forward prior implementations, evaluation results, and reasoning, plus a supervisor that monitors the trajectory for stagnation and redirects when the search plateaus. Over a seven-day run the main agent kept deciding what to inspect and test while the supervisor maintained forward progress. This is the durability pattern an iterative email-build-and-validate loop needs so a QA rejection restarts refinement instead of losing state.

Persistent memory carries forward prior implementations, evaluation results, compiler and profiler outputs, and accumulated reasoning, allowing the agent to resume from the current state. [articles/nvidia-developer/af3266a86f.md#c2]
