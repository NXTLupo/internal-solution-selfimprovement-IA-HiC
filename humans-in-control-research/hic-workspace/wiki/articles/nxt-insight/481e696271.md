Splitting one agent into role-scoped agents restores accuracy that a single prompt degrades

An AWS retail supply-chain team found SQL generation accuracy degraded as a single agent's prompt grew, and improved significantly after decomposing into Supervisor, Query, Detail, Research, Summary, and Action agents with a self-correction retry mechanism [articles/aws-retail-blog/b7ad106ca4.md#c3]. This role-scoped decomposition is the direct precedent for specifying discrete agent roles in the Deciem Figma-to-HTML pipeline (for example a parser agent, a component-mapping agent, an MJML build agent, and a QA agent). The finding grounds the objective's requirement to specify agent roles and skills rather than pack everything into one model.

When all capabilities were packed into a single agent's prompt, SQL generation accuracy degraded as the prompt grew. After decomposition, accuracy improved significantly [articles/aws-retail-blog/b7ad106ca4.md#c3]
