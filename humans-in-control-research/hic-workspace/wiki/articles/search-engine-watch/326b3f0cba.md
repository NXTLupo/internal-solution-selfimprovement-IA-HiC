# Google tests AI Mode upload menu in Search results

Source: [search_engine_watch](https://searchenginewatch.com/google-tests-ai-mode-upload-menu-in-search-results/)

Google tests AI Mode upload menu in Search results
Google seems to be bringing its AI Mode upload menu to the Search results page, replacing the usual magnifying-glass icon when users focus an existing query.
The change affects the search box on the results page.
When you click inside an existing search query, the box normally shows a magnifying-glass icon on the left. In the version we spotted, Google has replaced it with a + button.
Clicking the button opens a menu with Add images, Add files, and Create images. It also offers Gemini 3 Fast and Gemini 3 Pro.
The change brings AI Mode’s input options into the regular Search results page. The existing query stays in the search box, while the + button gives users options to add images or files or use other AI features.
This isn’t the first time Google has used a + button in Search. Google previously added one to the homepage search bar, where it offered options to upload an image or file for use with AI Mode.
The difference this time is where the button appears. Instead of appearing on the Google homepage, the + button shows up when an existing query is focused on the Search results page, taking the place of the search icon normally shown there.
We spotted the change in Firefox, although it did not appear in our tests with other browsers. This suggests Google may be testing the feature with a limited set of users rather than rolling it out broadly.
Google has not announced this specific change to the Search results page, so it may not be available to everyone.
