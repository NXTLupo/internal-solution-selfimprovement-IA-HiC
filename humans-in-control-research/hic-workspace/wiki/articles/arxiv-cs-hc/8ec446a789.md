# Vision Based Game Development Using Human Computer Interaction

Source: [arxiv_cs_hc](https://arxiv.org/abs/1002.2191v1)

A Human Computer Interface (HCI) System for playing games is designed here for more natural communication with the machines. The system presented here is a vision-based system for detection of long voluntary eye blinks and interpretation of blink patterns for communication between man and machine. This system replaces the mouse with the human face as a new way to interact with the computer.
