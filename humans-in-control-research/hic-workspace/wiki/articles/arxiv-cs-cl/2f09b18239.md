# GR-NLP-TOOLKIT: An Open-Source NLP Toolkit for Modern Greek

Source: [arXiv CS.CL](https://arxiv.org/abs/2412.08520v1)

We present GR-NLP-TOOLKIT, an open-source natural language processing (NLP) toolkit developed specifically for modern Greek. The toolkit provides state-of-the-art performance in five core NLP tasks, namely part-of-speech tagging, morphological tagging, dependency parsing, named entity recognition, and Greeklishto-Greek transliteration.
