# Efficient Spatial-Temporal Information Fusion for LiDAR-Based 3D Moving Object Segmentation

Source: [arxiv_cs_ro](https://arxiv.org/abs/2207.02201v1)

Accurate moving object segmentation is an essential task for autonomous driving. It can provide effective information for many downstream tasks, such as collision avoidance, path planning, and static map construction. How to effectively exploit the spatial-temporal information is a critical question for 3D LiDAR moving object segmentation (LiDAR-MOS). In this work, we propose a novel deep neural network exploiting both spatial-temporal information and different representation modalities of LiDAR
