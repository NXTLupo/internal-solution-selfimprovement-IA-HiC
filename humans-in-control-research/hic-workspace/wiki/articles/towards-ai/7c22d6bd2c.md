I found these holes and wrote this up myself. AI helped me line them up.

On Saturday morning I found my own API key in my own JavaScript.

I wasn’t looking for it. I was chasing a layout bug on a little app I’d built with Claude Code. I opened DevTools and searched the code for “describe” to find one function.

The key was sitting right next to it. A long string starting with `sk-`, in plain text.

The app is a lending shelf for the neighbors on my street. About thirty of us share a group chat and a lot of tools: you list what you own, someone borrows it, they bring it back. I’d posted the link in the chat the night before.
