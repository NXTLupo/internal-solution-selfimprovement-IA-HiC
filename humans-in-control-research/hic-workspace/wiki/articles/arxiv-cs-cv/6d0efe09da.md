# First Investigation Into the Use of Deep Learning for Continuous Assessment of Neonatal Postoperative Pain

Source: [arxiv_cs_cv](https://arxiv.org/abs/2003.10601v1)

This paper presents the first investigation into the use of fully automated deep learning framework for assessing neonatal postoperative pain. It specifically investigates the use of Bilinear Convolutional Neural Network (B-CNN) to extract facial features during different levels of postoperative pain followed by modeling the temporal pattern using Recurrent Neural Network (RNN).
