# Global Adaptive Filtering Layer for Computer Vision

Source: [arxiv_cs_cv](https://arxiv.org/abs/2010.01177v4)

We devise a universal adaptive neural layer to "learn" optimal frequency filter for each image together with the weights of the base neural network that performs some computer vision task. The proposed approach takes the source image in the spatial domain, automatically selects the best frequencies from the frequency domain, and transmits the inverse-transform image to the main neural network.
