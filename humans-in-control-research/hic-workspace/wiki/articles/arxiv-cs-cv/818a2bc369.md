# A Novel Approach to OCR using Image Recognition based Classification for Ancient Tamil Inscriptions in Temples

Source: [arxiv_cs_cv](https://arxiv.org/abs/1907.04917v1)

Recognition of ancient Tamil characters has always been a challenge for epigraphers. This is primarily because the language has evolved over the several centuries and the character set over this time has both expanded and diversified. This proposed work focuses on improving optical character recognition techniques for ancient Tamil script which was in use between the 7th and 12th centuries.
