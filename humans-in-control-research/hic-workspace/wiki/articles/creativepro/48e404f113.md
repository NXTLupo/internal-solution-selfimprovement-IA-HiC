# Mapping Paragraph Styles to PDF Tags in InDesign

Source: [creativepro](https://creativepro.com/mapping-paragraph-styles-to-pdf-tags-in-indesign/)

Mapping Paragraph Styles to PDF Tags in InDesign
Map Paragraph Styles in your InDesign document to the proper tags for accessible PDF creation.
In this InDesign how-to video, Colleen Gratzer helps you avoid a common mistake designers make when setting accessibility tags. She explains that while the Structure pane is used to create tags, it applies XML tags, which do not control PDF accessibility. Instead, Colleen demonstrates how to map styles to PDF tags either within individual Paragraph Style settings or all at once using the Edit All Export Tags panel.
