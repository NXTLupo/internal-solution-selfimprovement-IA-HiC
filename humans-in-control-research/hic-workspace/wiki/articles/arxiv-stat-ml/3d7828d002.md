# Active learning for data streams: a survey

Source: [arxiv_stat_ml](https://arxiv.org/abs/2302.08893v4)

Online active learning is a paradigm in machine learning that aims to select the most informative data points to label from a data stream. The problem of minimizing the cost associated with collecting labeled observations has gained a lot of attention in recent years, particularly in real-world applications where data is only available in an unlabeled form.
