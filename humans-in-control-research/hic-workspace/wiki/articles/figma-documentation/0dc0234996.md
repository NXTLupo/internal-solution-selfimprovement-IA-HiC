# Figma MCP collection: Figma + Developer Workflows | design systems, Code Connect, MCP, and Make (feat. Jake Albaugh)

Source: [Figma documentation](https://help.figma.com/hc/en-us/articles/36189347137047-Figma-MCP-collection-Figma-Developer-Workflows-design-systems-Code-Connect-MCP-and-Make-feat-Jake-Albaugh)

You learned the basics of what the Figma MCP server is and how to set it up throughout the lessons in this collection. But after you get everything set up, you may be wondering how you make Figma Design and Figma Make, the MCP server, and your agentic development tools in workflows that can improve your development process. This video by Jake Albaugh, Developer Advocate at Figma, may have some answers for you.
Join Jake as he walks through how you can connect your codebase to Figma using Code Connect, bring design context from Figma Design into agentic development tools with the Figma MCP server, and uses Figma Make to add functionality to design components. Stay until the end to learn some useful best practices!
