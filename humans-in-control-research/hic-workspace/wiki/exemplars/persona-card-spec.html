PHOTO GENERATION SPECIFICATION
AI PORTRAIT REQUIREMENTS
Production persona cards use AI-generated photorealistic portraits (Midjourney, Flux, or DALL-E 3). These are the exact prompting and CSS treatment specifications for the agent.
/* ─── AI PORTRAIT GENERATION PROMPT TEMPLATE ─── */

// Midjourney / Flux prompt structure:
"Professional headshot portrait of a [age] year old
 [ethnicity] [gender], [role-appropriate attire],
 neutral expression, direct eye contact, studio lighting,
 shallow depth of field, clean background,
 editorial photography style, shot on Phase One IQ4,
 150MP, 80mm lens --ar 1:1 --s 250 --v 6.1"

/* ─── CSS TREATMENT (applied to all persona photos) ─── */

.persona-photo {
  width: 100%;
  height: 240px;                 /* Fixed height, not aspect-ratio */
  object-fit: cover;             /* Fill container, crop overflow */
  object-position: center 15%;    /* Bias upward toward face */
  filter: grayscale(100%) contrast(1.2) brightness(0.95);
                                 /* High-contrast B&W editorial */
  border-radius: 0;             /* Sharp edges. NEVER rounded. */
  border: none;                /* No frame. Edge-to-edge. */
  display: block;              /* Remove inline gap */
}

/* ─── BANNED TREATMENTS ─── */

border-radius: 50%          /* Circular crop = AI slop signal */
border: Npx solid #00B7C3   /* Colored frame = childish */
filter: none                /* Full color clashes with brand */
box-shadow: *               /* No shadows in the NXT system */
background: radial-gradient /* No vignette/glow behind photo */
clip-path: circle()         /* No circular masking of any kind */
