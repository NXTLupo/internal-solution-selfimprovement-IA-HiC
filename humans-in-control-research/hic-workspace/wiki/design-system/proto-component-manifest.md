# #proto Component Manifest

The Analyst Desk model (Opus 4.8) reads this at runtime when a user invokes `#proto` / `#prototype`
to construct brand-correct prototypes from the design-pattern library. Every pattern below is a real
Figma COMPONENT on the dedicated pages `GOLD · #proto patterns (nxt)` (file iSQhAVM7SI4QHAWB7y9C2z,
page 403:2) and `GOLD · #proto patterns (nu)` (file z2v9Pvhg23hlljEitPBdAt, page 332:2). When you
generate a prototype, style every element with the EXACT brand tokens below - never invent colors,
fonts, or emoji icons.

## Brand token resolution (use as CSS variables in the generated prototype)
Resolve `--accent`, `--surface`, etc. to the active brand's hex. Bind in the prototype's :root.

| token (CSS var) | Figma variable | NXT value | NU value |
|---|---|---|---|
| --accent | color/accent | #B8B800 (chartreuse) | #C8102E (Huskies red) |
| --on-accent | color/rail (NXT) / color/paper (NU) | #0D0D0D | #FFFFFF |
| --surface | color/paper | #FFFFFF | #FFFFFF |
| --panel / --s2 | color/ecru | #F2F1EA | #F2F1EA |
| --border | color/hairline | #DDDDD6 | #DDDDD6 |
| --text | color/ink | #141414 | #16233C |
| --muted | color/grey | #73757A | #73757A |
| --rail | color/rail | #0D0D0D | #0E1626 |
| --ok (status) | color/success (NXT) / color/source (NU) | #0CCE6B | #1D6E64 |
| --cool / --source | color/cyan (NXT) / color/source (NU) | #00B7C3 | #1D6E64 |
| font sans (--sans) | font/body | Archivo | Lato |
| font mono (--mono) | font/mono | IBM Plex Mono | Lato |
| font display (--display) | font/display | Saira Condensed | Lato |

ICONOGRAPHY RULE (mandatory): use FLAT, MONOCHROMATIC SVG LINE ICONS (stroke=currentColor, 2px,
round caps), recolored to --muted / --text / --on-accent. NEVER use color emoji (no wrench/brain/mic/thumb glyphs) - they
are an AI-slop tell. Inline SVG paths are provided per component below.
