# #proto Component Manifest

The Analyst Desk model (Opus 4.8) reads this at runtime when a user invokes `#proto` / `#prototype`
to construct brand-correct prototypes from the design-pattern library. Every pattern below is a real
Figma COMPONENT on the dedicated pages `GOLD · #proto patterns (nxt)` (file iSQhAVM7SI4QHAWB7y9C2z,
page 403:2) and `GOLD · #proto patterns (nu)` (file z2v9Pvhg23hlljEitPBdAt, page 332:2). When you
generate a prototype, style every element with the EXACT brand tokens below - never invent colors,
fonts, or emoji icons.

## Brand token resolution (use as CSS variables in the generated prototype)
Resolve `--accent`, `--surface`, etc. to the active brand's hex. Bind in the prototype's :root.
