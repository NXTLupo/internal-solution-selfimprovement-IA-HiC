## 4. The P0 orphan, in detail (the real violation)

The proxy HTML-artifact generic path (`proxy/app.py:18843-18856`) builds the prompt via
`_artifact_generation_prompt(kind, brand, goal, corpus, skill_md, ...)` and prepends learned
constraints + a no-fabrication directive, but **never injects the Figma tokens.** Consequences
(evidence-grounded):
1. **Hardcoded + stale brand.** `_artifact_generation_prompt` hardcodes NU as `Roboto Condensed` +
   `Open Sans` (proxy/app.py ~18073-18075) — WRONG: `figma-tokens.json` NU is the single-typeface
   **Lato** system (2026-06-15 redesign). The HTML path regressed and never tracked Figma. NXT colors
   are likewise hardcoded literals, not token references.
2. **Broken output.** Generated artifacts (`hic-workspace/artifacts/*.json`) reference undefined CSS
   vars (`var(--nxt-teal)`, `--nxt-lime`, ...) that are never defined in the self-contained HTML, so
   they fall back to browser defaults = visually broken.
3. **The fix already exists, unused.** `/api/design-tokens?format=prompt` (proxy/app.py:5095-5206)
   already emits a ready-to-inject "use these EXACT values, do NOT invent hex/fonts" block — it is
   wired to the slide path and NOT to the artifact path.

This is the exact "the model invents/hardcodes design patterns that already exist in the system"
failure the directive forbids.

## 5. Fix plan (Verbalized Sampling + Reinforcement Inference)

### VS pass — candidate fix architectures (VS-CoT, k=4, moderate-tail)

<vs_thinking>
MODAL fix (high p, REJECT): "just correct the hardcoded NU fonts to Lato in _artifact_generation_prompt."
It fixes today's wrong-font bug but RE-COMMITS the never-hardcoded sin (principle #7) and drifts again
on the next Figma change. The directive is about GROUNDING, not patching one literal. Reject.
Evidence pointing away: the slide path already solved this with live token injection; the meta-principle
says CONVERGE onto one source, don't duplicate/hardcode. So the real design space is "wire the HTML path
to the SAME live-token source, and how widely to converge."
</vs_thinking>

| # | Frame | Candidate | p |

| 1 | modal (REJECT) | Hardcode the correct Lato/NXT values in `_artifact_generation_prompt`. | 0.45 |
| 2 | shifted (RECOMMEND) | Inject the LIVE token block into the artifact prompt by calling the in-process token builder behind `/api/design-tokens?format=prompt`; DELETE all hardcoded brand fonts/colors from `_artifact_generation_prompt`; require the model to emit a complete `:root{}` with every token so the self-contained HTML defines its own vars (kills the undefined-var breakage). | 0.16 |
| 3 | tail (CONVERGE) | Same as #2 but extract ONE shared `build_design_token_prompt_block(brand)` helper and route BOTH the SPA chat path and the proxy artifact path + the skill-routed hashtags through it = a single token-injection chokepoint (no parallel logic). | 0.07 |
| 4 | tail | Add a deterministic post-generation gate: scan artifact HTML for literal brand hex / non-token fonts / undefined `var(--*)` and reject+repair, mirroring the slide no-hardcode ceiling. | 0.05 |

**COMMIT: #2 implemented THROUGH #3 (one shared token-block helper), plus #4 as the gate.** Rationale:
#2 fixes the orphan at its root with infra that already exists; #3 is the converge-don't-duplicate move
so the HTML path, chat path, and skill-routed hashtags can never drift apart again; #4 is the
deterministic backstop (the post-processor the vision trusts over prompt instructions).

### Phased plan (each phase gated)
- **P0a — wire live tokens into the HTML-artifact prompt.** In `proxy/app.py`, build the token block
  (the existing `format=prompt` builder) and prepend it to the artifact prompt alongside the learned
  constraints; DELETE the hardcoded NU `Roboto Condensed`/`Open Sans` and NXT literal colors from
  `_artifact_generation_prompt`; instruct the model to emit a complete `:root{}` token block.
  *Gate:* a freshly generated `#brief` (NU) uses Lato + defines all `var(--*)`; no literal brand hex.
- **P0b — converge to one helper (#3).** Extract `build_design_token_prompt_block(brand)` and call it
  from the artifact path AND have the skill-routed visual hashtags use it. *Gate:* one code path; SPA
  chat token log + artifact token log show identical token source.
- **P1 — `#mindmap` grounding.** Confirm the mind-map renderer is token-bound; if its generation can
  emit colors, inject the token block. *Gate:* mind-map renders from tokens only.
- **P2 — post-gen no-hardcode gate (#4).** Add a proxy-side scan that rejects/repairs artifact HTML
  containing literal brand hex, non-token fonts, or undefined `var(--*)`. *Gate:* a deliberately
  hardcoded artifact is caught.
- **P3 — regenerate stale artifacts.** The existing `hic-workspace/artifacts/*.json` were built with
  wrong NU fonts + undefined vars; flag for regeneration (do not silently keep them).
- (Separately, the 5 render-layer token-fidelity DEFECTS in section 2 are a pre-existing burn-down,
  not part of this orphan fix.)
