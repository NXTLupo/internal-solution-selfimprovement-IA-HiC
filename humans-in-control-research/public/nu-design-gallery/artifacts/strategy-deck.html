Archetype 07

Problem / solution

55/45 split with a 1px vertical divider. Left names the problem with one hero stat; right gives 2–3 solution points with a short accent rule before each.

When
Pain + remedy
Left
Red label, one stat
Right
Cyan label, 2–3 pts
Problem

Coordinators discover the dropout after the cycle has closed.

silence-attrition rate
38%

A single untargeted template email fires on day 7 and is identical for a student with one open application and a student with seven. 5

Solution

Triage at day five, with an explain view.

  1. Day-5 silence trigger via Handshake webhook routes flagged students into a ranked coordinator queue.
  2. Explain view per entry shows the top three contributing signals in plain English. Trust before recommendation.
  3. Personalized nudge mentions the student's actual application count, not a template.

Reading the deck · selection rules
  1. First slide? → Title (01)
  2. Section break? → Section header (02)
  3. Contains specific stats? Trend / comparison → Insight chart (04). Otherwise → Data panel (03).
  4. Contrasts pain with remedy? → Problem/Solution (07)
  5. 3+ discrete findings or quotes? → Bento (06)
  6. Dedicated data / matrix slide? → Full-bleed viz (05)
  7. Default → Data panel (03)
