Anatomy of an artifact.

Every research artifact in the library is built from a small vocabulary of shared elements — a masthead, an eyebrow, a finding, a citation chip, a maturity bar, a signal dot, a dense table. This page is the canonical reference: every element, with the rule it follows and the HTML that produces it.

Design tokens

§01

Color palette

§02

The everyday "primary" UI color is ink-900, not red. Northeastern red is a scalpel — it marks the critical state, the target maturity, the one verbatim quote per page. It is never a divider, never a fill, never decoration.

Masthead

§04

Every artifact opens with the same masthead. Single row: brand seal, kicker + finding-title, three meta blocks on the right. No methodology blurb. No subtitle. No date line below the title.

Eyebrow + finding

§05

Inside any card, the pattern is .art-eyebrow over .art-finding. The finding is always a complete sentence stating a conclusion — never a topic label like "Market overview."

Critical gap · G-02
No silence-detection in the application funnel costs the cycle 38% of stalled students.
Cincinnati flags at day 5; Northeastern fires a template email at day 7 and waits.
Funnel
Application funnel issues

Citation chips

§06

Citations live inline as small monospace chips, not as a separate footnote strip below the slide. A consolidated source index sits once, at the foot of the document.

The placement-to-donor handoff lags 11 days 3 against a 5-day peer benchmark 7, while VP-OPS-09 names sunset as the funding posture. One verbatim quote per page can carry a brand-red marker: v.

/* Inline numeric chip */ …lags 11 days <sup class="cite" data-src="Drexel '24">3</sup> /* Named chip (longer label) */ <span class="cite-chip">VP-OPS-09</span> /* Verbatim quote marker — brand red */ <sup class="cite" data-verbatim="true">v</sup>

Pills + tags

§07

Pills are pure status (success / warning / error / progress / special). Tags are categorical, neutral. Both sit at 18px height for density; the --lg variant is 22px.

on track needs attention critical in progress exploratory verbatim primary muted quick win category
<span class="pill pill--success">on track</span> <span class="pill pill--warning">needs attention</span> <span class="pill pill--error">critical</span> /* Size variant */ <span class="pill pill--lg pill--success">quick win</span>

Signal dots

§08

For relationship-health and integration-health surfaces, an 8px colored dot communicates state without a label. Never use the words "at risk" or "failing" — the dot does the work, the surrounding row tells the story.

Maturity bar

§10

Dense tables

§11

.dtable packs data tighter than a default table: 10 px uppercase headers, 8 px row padding, single-pixel dividers, alternating-row free (the table doesn't need stripes when borders are this clean). For wide tables, add .dtable--sticky to lock the first column.

The thirteen don'ts

§13

The patterns that creep back in if you don't watch them. Each is something a research artifact has, by default, that earns no information per pixel.

Micro-labels above headingsremove
C-03 · sunset 2027-Q1
Retire the volunteer-management platform.

Tiny ID · status stamps above titles add nothing. The status is already in a pill in the corner; the ID is in the first column. Remove.

"Primary archetype" suffixesremove
Persona
Maya Rodríguez
MGO · 7 yrs · Boston · primary archetype

"Primary archetype," "primary persona," "high confidence" — quality flags that don't tell the reader anything they can't see. Remove.

Methodology blurbs at the topremove
Methodology: We synthesized findings across 248 chunks, applying verbalized sampling across k=8 candidates filtered by 0.10 probability + ≥2 evidence anchors…

Methodology lives in the masthead meta blocks (corpus size, external citation share). A separate "Methodology" preamble is process-aware language that erodes credibility.

"EVIDENCE GAP" annotationsremove
Donor-stewardship workflow.
EVIDENCE GAP — [needs baseline measurement]

QA-style annotations are for the team, not the reader. If evidence is thin, narrow the claim to what is evidenced. Never write the model's awareness of its gaps into the artifact.

Slide numbers on documentsremove
Section 03 · Diagnosis
03 / 18 — page footer chrome

Slide numbers belong on slides. On a scrolling document, the section index does the navigation work — page numbers are decorative.

"Industry average" peer comparisonsnever
NU vs. Industry Average
Industry average for placement-to-donor lag: 8 days.

"Industry average" and "peers collective" are invented entities. Always name four or more specific peer institutions with traceable data.
