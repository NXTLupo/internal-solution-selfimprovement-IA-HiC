2. DATA COLLECTION LAYER

2.1 Source Auto-Enablement

File: services/analyticalLensService.ts — detectAnalyticalLens() + recommendDataSources()

The system reads the research goal + uploaded document filenames, detects domain keywords, selects the appropriate analytical lens, and enables ONLY relevant source categories. No manual selection.

2.2 Source Pre-Filter

File: App.tsx — After source IDs are built, a domain-aware pre-filter removes irrelevant sources (e.g., ML model registries, AI benchmarks, framework docs removed for fundraising research).

2.3 Corpus Construction

File: services/researchFabricOrchestrator.ts — mergeResultsToCorpus()

Key implementation decisions (verified):
  • No items are dropped. filterAndScoreItems() scores all items 0-100 for relevance but KEEPS everything. Items are sorted by score, highest first.
  • No static tier labels. Sources are labeled by NAME only. The corpus header says: "Source value is determined by YOU based on actual contribution to the research objective."
  • Reddit limited to 30 items per subreddit (was 100). Prevents social data from dominating the corpus.
  • Reddit URLs use https://www.reddit.com (fixed from broken reddit.comhttps:// concatenation).

3.2 Wiki Integration with Generation Pipeline

File: App.tsx line 1592 — loadGenerationContext() fetches wiki pages before creating the GenAISession. The assembled wiki knowledge is passed as the 5th parameter to the constructor and injected into the system prompt.

LIMITATION: Wiki pages are loaded via fetch() from Nginx. If the fetch fails (network, CORS, missing file), the system falls back to static framework prompts only. The narration still fires with a fallback message but wiki knowledge is NOT injected.

4.2 Post-Analysis Confidence Scoring

Confidence is computed AFTER the AI reads everything, based on 5 measurable factors: source breadth, cross-source convergence, data specificity, research goal coverage, evidence freshness. Each scored 0-100. The AI also ranks which source categories actually contributed most to the research objective.

4.3 Citation Resolver

File: services/citationResolver.ts — Called via dynamic import in App.tsx line 967 after all deliverables are generated. Walks the entire result tree and replaces [CHUNK_XXX] references with (Source: Document Name, Year).

4.4 Anti-Slop Detection

File: services/wikiService.ts — detectBannedPhrases() scans generated text for 18 banned consultant-speak phrases. Results are narrated in the reasoning stream.

6.2 Strategy Deck

Rumelt's Kernel enforced (diagnosis + guiding policy + coherent actions). 3-layer depth on every paragraph (observation + implication + recommendation with evidence). Visual direction: stat callouts, data charts, evidence blocks — not clip-art.

6.3 Theme Extraction

6 analytical lenses. Source diversity required — themes must cite 2+ different source names. Minimum 12 themes for large corpora. Mandatory full-corpus coverage — the AI must cite chunks from across the full range.

Uploaded documents labeled PRIORITY 1. Reads research objective first. 5-factor confidence scoring. Source contribution ranking. Full CHUNK_XXX citation requirement.
