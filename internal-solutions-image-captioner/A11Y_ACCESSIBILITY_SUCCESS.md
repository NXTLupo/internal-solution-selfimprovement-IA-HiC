## 🤖 **Enhanced Claude AI Prompting:**

### **Accessibility-Focused AI Instructions:**
```
"Generate a WCAG 2.1 compliant alt text description for this image. 
Focus on the essential visual information that would help someone 
using a screen reader understand the content and context. Be 
descriptive but concise, mentioning key elements, people, actions, 
text, and important visual details that convey the image's purpose 
and meaning. Avoid starting with 'An image of' or 'A photo of'."
```

### **Professional Alt Text Standards:**
- **Contextual Descriptions**: What would screen reader users need to know?
- **Purpose-Driven**: Focuses on the image's function and meaning
- **WCAG Guidelines**: Follows established accessibility standards
- **Concise & Clear**: Optimal length for screen reader consumption
- **Action-Oriented**: Describes what's happening, not just what's visible
