### Character Consistency Protocol
When creating visual campaigns with recurring characters or personas:
1. Establish a **Character Reference Sheet** with locked visual traits
2. Maintain trait descriptions verbatim across all scene generations
3. Vary only environment, pose, and lighting
4. Use consistent style anchors (photographer/artist references)
