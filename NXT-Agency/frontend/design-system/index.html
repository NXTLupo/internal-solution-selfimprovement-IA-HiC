Principles
Visual Language
No Shadows
All depth via background blur + layered opacity. Never use drop-shadow or box-shadow.
Frosted Glass
backdrop-filter: blur(32px) over teal/dark overlays for depth and elegance.
Minimal Radius
2px for buttons/inputs, 4px for nav. Circles only for icon buttons (50%).
High Contrast
White/lime text on very dark backgrounds. WCAG AA+ on all combinations.
Dark First
All backgrounds use the dark palette (#141414, #242424, #3a3a3a). White is for forms only.
1px Progress Bars
Ultra-thin progress indicators: white for active, lightest for inactive segments.
