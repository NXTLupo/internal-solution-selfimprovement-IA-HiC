# NXT Humans Brand Style Guide

## Brand Overview
NXT Humans is a forward-thinking AI research and development company focused on human-centered AI solutions. The brand represents innovation, intelligence, and humanity working together to advance technology that enhances human experience.

## Logo
- Primary logo: Located at `/internal-solutions-socialresearch/frontend/public/nxt-humans-logo.png`
- The logo should be displayed prominently in the header of all applications
- Minimum padding around logo: 16px

## Color Palette

### Primary Colors
- **Cyan Primary**: #01C4C8 (rgba(1,196,200,1))
  - Used for primary buttons, key UI elements, and accents
  - Variants: 
    - 80% opacity: rgba(1,196,200,0.8)
    - 60% opacity: rgba(1,196,200,0.6)
    - 40% opacity: rgba(1,196,200,0.4)
    - 20% opacity: rgba(1,196,200,0.2)

- **Dark Blue**: #121B26
  - Used for backgrounds, footers, and dark UI elements
  - This creates high contrast with light text

### Secondary Colors
- **Light Grey**: #5A6275 
  - Used for secondary backgrounds, cards, and lighter UI elements
- **Medium Grey**: #4A5165
  - Used for borders, separators, and medium-contrast UI elements

### Text Colors
- **Dark Text**: #333333 
  - For primary text on light backgrounds
- **Light Text**: #FFFFFF
  - For text on dark backgrounds
- **Grey Text**: #666666
  - For secondary text, captions, and less emphasized content

## Typography
- **Primary Font**: 'Segoe UI', -apple-system, BlinkMacSystemFont, Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif
- **Header Sizing**:
  - H1: 1.8rem (bold)
  - H2: 1.5rem (bold)
  - H3: 1.25rem (semibold)
  - H4: 1rem (semibold)
- **Body Text**: 1rem/16px (regular)
- **Small Text**: 0.875rem/14px (regular)

## UI Elements

### Buttons
- **Primary Button**:
  - Background: Cyan Primary (#01C4C8)
  - Text: White (#FFFFFF)
  - Border: None
  - Border Radius: 4px
  - Padding: 0.75rem 1.5rem
  - Hover: Darken background by 10%

- **Secondary Button**:
  - Background: Transparent
  - Text: Cyan Primary (#01C4C8)
  - Border: 1px solid Cyan Primary
  - Border Radius: 4px
  - Padding: 0.75rem 1.5rem
  - Hover: Light Cyan background (rgba(1,196,200,0.1))

### Cards
- Background: White (#FFFFFF)
- Border Radius: 8px
- Box Shadow: 0 4px 6px rgba(0, 0, 0, 0.1)
- Padding: 1.5rem

### Form Elements
- Input Border Radius: 4px
- Input Border: 1px solid #DEE2E6
- Input Focus: Border color Cyan Primary, with subtle glow
- Form Element Spacing: 1.5rem between groups

## Layout
- Consistent padding: 1.5rem for containers
- Max width for content area: 1200px
- Responsive breakpoints:
  - Mobile: Up to 768px
  - Tablet: 768px to 1024px
  - Desktop: 1024px and above

## Brand Voice
- Clear and concise
- Professional but approachable
- Emphasizes human-centered technology
- Focuses on insights and intelligence
- Avoids excessive jargon
