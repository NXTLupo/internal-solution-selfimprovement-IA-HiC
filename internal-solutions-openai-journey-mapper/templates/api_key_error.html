API Key Error

Invalid or Missing OpenAI API Key

The AI Journey Mapper application requires a valid OpenAI API key to function.

The current API key is either missing, expired, or invalid.

How to Fix This Issue

To use this application, you need to provide a valid Anthropic API key. Here's how:

Option 1: Set the API key through the command line

Run the application with your API key as an argument:

./update_openai_key.sh your-api-key-here

Option 2: Set the API key in your environment

Add the following line to your shell profile (.bashrc, .zshrc, etc.):

export OPENAI_API_KEY="your-api-key-here"

How to Get an OpenAI API Key

  1. Visit platform.openai.com
  2. Create an account or log in
  3. Navigate to the API Keys section
  4. Create a new API key

API keys start with sk- and should be kept secret and secure.

Using o3 Reasoning Model

To use the o3 specialized reasoning model, your organization must be verified by OpenAI. If you don't have access to o3, the application will automatically fall back to GPT-4o.
