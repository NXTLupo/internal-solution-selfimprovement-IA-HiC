API Key Error

Invalid or Missing Anthropic API Key

The AI Journey Mapper application requires a valid Anthropic API key to function.

The current API key is either missing, expired, or invalid.

How to Fix This Issue

To use this application, you need to provide a valid Anthropic API key. Here's how:

Option 1: Set the API key through the command line

Run the application with your API key as an argument:

./start_with_api_key.sh your-api-key-here

Option 2: Set the API key in your environment

Add the following line to your shell profile (.bashrc, .zshrc, etc.):

export ANTHROPIC_API_KEY="your-api-key-here"

How to Get an Anthropic API Key

  1. Visit console.anthropic.com
  2. Create an account or log in
  3. Navigate to the API Keys section
  4. Create a new API key

API keys start with sk-ant- and should be kept secret and secure.
