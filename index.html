Runs you can compare

How a request moves

Your words set the subject, you start the plan, code checks the result

Rules read a request before any model does, and a plan card shows how it was understood before anything runs. Select a step to read what it does.

Your request

The subject is what the work is about. The brand, the audience, the shape, the level of detail and the period are read out of the same sentence as settings, and never become part of the subject.

“for store operations leaders, going back 90 days” became an audience and a period
Rules before any model

The router reads the request before any model sees it. A hashtag, a named output or a recording is placed at once. A question about today is answered in the chat from dated web results, with no plan and no artifact.

2.8 s to a plan card; 13.6 s for today’s news
You start the plan

The plan card says how it understood you: the subject, who it is for, where it is filed and what it carries over. You choose the data packs, the period, the depth and the brand. Each step shows its measured time.

Nothing runs until you press Start
Research, then build

A deep request reads every source in the chosen packs, ranks what it finds by meaning, and keeps the sources that are on the subject and inside your period. One engine then builds the work at the level of detail you asked for. The card updates in place, and every source on it opens while the run carries on.

200 pack sources read in 201 s
Code checks the result

Code checks the finished work: each quote found in its source, each source dated inside the period, whole sentences, slides that fit, no text under 10 pt. A hard failure gets one repair pass, kept only if it scores better. Whatever is still wrong is listed on the card as needing review.

27 of 27 quotes found on a journey map
A card you can open

The card opens the live page: filters, tabs and cards respond. Every artifact downloads as PDF and as editable PowerPoint, and every source row shows its publication, date and address.

Mind maps and diagrams export as editable shapes, never a picture
While you are away

When nobody is using it, it checks its own work again

An idle pass starts when no task, chat or picture is in progress and stops the moment you type. Each job in it appears on the page as a task you can open, so nothing happens out of sight.

Skills are packages

Each agent skill is a folder with its steps, a spec and test cases. The agent loads one by name when a request calls for it, and a lint checks that every step names its check and its recovery.

Measured with and without

A skill earns its place in trials: the same cases run with the skill and without it. The research skill passed 11 of 11 cases with it and 10 of 11 without, and no single step could be cut.

Memory in tiers

Notes are kept about you, about an engagement or about one conversation. Conversation notes expire after seven days unless you keep them, and you can forget any note from the Memory panel.

Measured

The same requests now finish in minutes

Each pair is the same request on the same machine: its first measured run in the field tests, and its run after the fixes of 23 to 27 November 2026.

How the parts work

The suite, HiC and IA Next, drawn as they run

The four drawings below are the mechanisms behind the original suite and IA Next. Each arrow says what moves across it.

IA Suite

How a chat message reaches a service

The agent talks to every service through a small MCP wrapper. It reads each wrapper's tool list once when it starts, then calls tools by name while Claude works through the request.

Humans in Control (HiC)

How HiC turns sources into a cited deck

HiC writes every source into a wiki before it writes anything for the client. The deck is drafted from pointers into that wiki, so each claim can be traced back to a stored passage.

The wiki remembers

Each chunk keeps its source, its type and its character span. A later run on a related question starts from those chunks before it fetches anything new.

Retrieval follows the question

HiC seeds evidence from the user's objective and the manifest's links, then reranks. A well-written article on the wrong question ranks low.

The deck stays editable

The exporter opens each finished slide in Chromium, measures every element, and writes it to PowerPoint as a real text box or shape.

IA Next

What IA Next does after you ask for something

The agent turns your request into a task with steps and a budget. Anything that costs money waits for your approval, and every quote is checked before the result reaches the conversation.

One computer

Running both systems on one machine

The suite and IA Next are separate compose projects with their own networks and data, and no port appears in both. IA Next reaches HiC only through the host, and only when you ask for HiC's work.

Run it locally

Start the suite, IA Next or IA Next Local

The suite and IA Next read API keys from the repository's root .env. IA Next Local needs no key: it needs Ollama on the host with the models listed in its guide.
