NXT Humans

Intelligence Augmentation

NXT Humans consultants use this platform to answer a client's question with evidence. Agents collect articles, public data and the client's own files, keep them in a wiki the whole team can search, and draft the decks, personas, journey maps and prototypes that go back to the client. Each quote in the finished work links to the passage it came from.

The newer workspace. You talk to one agent, it hands the work to specialists, and it asks before spending money.

IA Suite

How a chat message reaches a service

The agent talks to every service through a small MCP wrapper. It reads each wrapper's tool list once when it starts, then calls tools by name while Claude works through the request.

Humans in Control (HiC)

How HiC turns sources into a cited deck

HiC writes every source into a wiki before it writes anything for the client. The deck is drafted from pointers into that wiki, so each claim can be traced back to a stored passage.

The wiki remembers

Each chunk keeps its source, its type and its character span. A later run on a related question starts from those chunks before it fetches anything new.

Retrieval follows the question

HiC seeds evidence from the user's objective and the manifest's links, then reranks. A well-written article on the wrong question ranks low.

The deck stays editable

The exporter opens each finished slide in Chromium, measures every element, and writes it to PowerPoint as a real text box or shape.

IA Next

What IA Next does after you ask for something

The agent turns your request into a task with steps and a budget. Anything that costs money waits for your approval, and every quote is checked before the result reaches the conversation.

One computer

Running both systems on one machine

The suite and IA Next are separate compose projects with their own networks and data, and no port appears in both. IA Next reaches HiC only through the host, and only when you ask for HiC's work.

Run it locally

Start the suite, IA Next, or both

Both read API keys from the repository's root .env. Anthropic is required; OpenAI and Gemini keys turn on more of the specialists. Copy .env.example to start.

IA Suitethen open localhost:8000
# from the repository root
cp .env.example .env
docker compose -f docker-compose-all.yml up -d
docker compose -f docker-compose-all.yml ps
IA Nextthen open 127.0.0.1:9400
# same .env; it can run beside the suite
docker compose -f ia-next/ia-next.compose.yml up -d --build
curl http://127.0.0.1:9400/health
